# 06. フロントエンド画面設計

React + TypeScript + Vite + Zustand + Tailwind CSS。キャンバス操作は Konva.js(react-konva)。
ルーティングはプロジェクト単位のウィザード型 + 自由遷移のハイブリッド:

```
/                          Home
/projects/new              Upload
/projects/:id/interview    Interview
/projects/:id/parts        PartsEditor(中心画面)
/projects/:id/mask/:partId MaskEditor
/projects/:id/preview      Preview
/projects/:id/export       Export
```

画面上部に共通ステッパー(アップロード → ヒアリング → パーツ設計 → マスク → プレビュー → 出力)を表示し、`project.status` に応じて完了マークを付ける。

## 10.1 Home 画面

- 新規プロジェクト作成ボタン(→ Upload)
- 既存プロジェクト一覧(サムネイル = normalized.png 縮小版、名前、更新日、ステータスバッジ)
- 最近使ったプロジェクト(先頭に固定)
- プロジェクト削除(確認ダイアログ付き)

## 10.2 Upload 画面

- ドラッグ&ドロップ + ファイル選択(PNG/JPG/WEBP)
- プレビュー表示
- プロジェクト名入力(デフォルト: ファイル名)
- 画像情報表示: 解像度 / アルファ有無 / カラープロファイル / ファイルサイズ
- 「作成して正規化」→ POST /projects → normalize → Interview へ

## 10.3 Interview 画面

`GET generate-questions` の `QuestionList` を動的レンダリング(MVPは静的質問セット)。

| 質問 | UI |
|---|---|
| 品質レベル(簡易/標準/高品質/商用品質) | セグメントボタン |
| 使用目的(VTube Studio / nizima / ゲーム / 配信 / その他) | セレクト |
| 顔の可動域(小/中/大) | セグメントボタン |
| 目(瞬きのみ/目線移動/笑顔目/ジト目) | 複数選択チップ |
| 口(開閉のみ/あいうえお/歌唱向け) | セグメントボタン |
| 髪揺れ(前髪/横髪/後ろ髪/アホ毛) | 複数選択チップ |
| 装飾(ピアス/リボン/メガネ/帽子 等) | 複数選択チップ |
| 腕を動かすか | トグル |
| 表情差分が必要か | トグル |

「おまかせ」選択肢を全質問に用意。回答は `PUT /preferences` で保存 → 「AI解析を実行」ボタンで `POST /analyze` → PartsEditor へ。

## 10.4 PartsEditor 画面(中心画面)

4ペインレイアウト:

```
┌──────────┬──────────────────────┬──────────────┐
│ 左:       │ 中央: 画像キャンバス     │ 右: 選択パーツ  │
│ パーツツリー│ (Konva.js)            │ 詳細設定パネル  │
│           │ - 元画像表示            │              │
│           │ - bbox オーバーレイ      │              │
│           │ - マスク半透明重畳       │              │
├──────────┴──────────────────────┴──────────────┤
│ 下: 処理ログ / 品質チェック結果(タブ切替)               │
└──────────────────────────────────────────────────┘
```

**左ペイン(パーツツリー)**
- `group` 階層でツリー表示(Hair/Front → front_hair_01, ...)
- ドラッグ&ドロップで z_order / group 変更
- 表示/非表示アイコン、ロックアイコン、マスク生成状態バッジ(未生成/生成済/編集済)
- パーツ追加(標準テンプレートから選択 or 空パーツ)/ 削除 / 複製

**中央ペイン(キャンバス)**
- ズーム(ホイール)/ パン(スペース+ドラッグ)
- 選択パーツの bbox をハンドル付きで編集
- 全パーツ bbox の薄表示 ON/OFF
- 選択パーツのマスクを色付き半透明で重畳表示
- Phase 2: positive/negative point の打点 UI

**右ペイン(詳細設定)**
- 表示名(JP/EN)、group、z_order、part_type
- segmentation.method 選択、bbox 数値入力、text_prompt
- overlap_bleed_px / edge_feather_px スライダー
- needs_inpaint_under トグル + 理由
- Live2D usage / deformer hint / physics hint(タグ入力)
- 品質優先度、manual_review_required
- ボタン: 「このパーツのマスク生成」「マスク編集へ」「レイヤー生成」

**下ペイン**
- 処理ログ(ジョブ進捗をポーリング表示)
- 品質チェック結果(issue クリックで該当パーツを選択)

**ツールバー**: 全マスク一括生成 / 全レイヤー生成 / 合成プレビュー / 品質チェック / 保存(PUT /parts)

## 10.5 MaskEditor 画面

- 中央: キャンバス(元画像 + マスク色付き重畳)
- ツール: 追加ブラシ / 消しブラシ / ブラシサイズスライダー / 硬さ(Phase 1.5)
- Undo / Redo(ストローク履歴ベース、フロント側で完結)
- 表示制御: マスクON/OFF / 元画像透過度スライダー / レイヤー単体表示(切り抜き結果即時確認)
- 後処理ボタン(サーバー実行): 境界ぼかし / 膨張 / 収縮 / 穴埋め / 小ノイズ除去 → `POST /masks/{id}/refine`
- 保存(PUT /masks/{part_id})→ レイヤー再生成を自動トリガー
- 未保存離脱時の確認ダイアログ

実装: Konva.js のオフスクリーンキャンバスにストロークを描画し、保存時に grayscale PNG へエンコード。ピクセル座標は常に正規化画像座標系(ズームはビュー変換のみ)。

## 10.6 Preview 画面

- 全レイヤー合成表示(visible フラグ・z_order 反映)
- 表示モード切替: 合成 / 元画像 / 差分ヒートマップ / 交互点滅(A/B比較)
- レイヤー順リスト(この画面でも並べ替え可能)
- 透明フチチェック表示(EDGE_ARTIFACT 検出箇所をマーカー表示)
- 差分統計(差分ピクセル数 / 率)

## 10.7 Export 画面

- 品質レポート表示(overall_score のゲージ + issue 一覧、severity 色分け)
- score < 50 の場合は警告し「強制出力」チェックを要求
- 出力ボタン: PSD / layers.zip / JSON一式 / rigging_plan.md
- 出力履歴とダウンロードリンク
- 「Cubism Editor への読み込み手順」ガイド表示

## 状態管理(Zustand ストア設計)

| ストア | 責務 |
|---|---|
| `projectStore` | 現在のプロジェクト、一覧、preferences |
| `partsStore` | parts.json のワーキングコピー、選択パーツ、dirty フラグ、保存 |
| `maskEditorStore` | ストローク履歴、Undo/Redo スタック、ブラシ設定 |
| `jobStore` | 実行中ジョブのポーリングと進捗、ログ蓄積 |

原則: サーバーのファイルが真実。ストアは編集バッファであり、保存操作で明示的に同期する(自動保存はしない — Live2D 制作者の「手動保存文化」に合わせる)。
